# Personal IP asset contract

`ip-placeholder.svg` is a temporary asset, not the final character design.

The canonical paths live in `data/profile.ts` and cover six placements: Hero, Logo, favicon, Loading, 404 and Footer. If each placement needs a different crop or pose, add separate files here and update only those paths.

Recommended source exports:

- Hero: transparent PNG or WebP, at least 1600 px on the longest edge.
- Logo and favicon: square SVG or transparent PNG with a clear silhouette at 32 px.
- Loading, 404 and Footer: transparent SVG, PNG or WebP with generous safe space.
